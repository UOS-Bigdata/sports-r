# 아버지·아들 키 실습 자료

- 파일: `father-and-son.csv`
- 출처: https://uos-bigdata.github.io/bigdata-exercise/_downloads/4480b104e6e159a32c7d5a0b03cf4684/father-and-son.csv
- 내려받은 날짜: 2026-10-02
- 첨부 「9-1장 교과서」에서 사용한 공개 CSV를 그대로 저장했습니다.
- 1,078개 관측값. `fheight`: 아버지 키, `sheight`: 아들 키. 두 열의 원본 단위는 **inch**입니다.
- 3장 R 코드는 위의 공개 URL에서 직접 자료를 읽고 두 변수에 2.54를 곱하여 cm로 변환합니다. 이 파일은 원본 단위 그대로 보관한 사본입니다.
- CSV에는 가족 식별자나 표집 과정에 대한 정보가 없습니다. 현재 집단에 대한 대표성이나 관측쌍 사이의 독립성이 이 파일만으로 확인되는 것은 아닙니다.
