2일차 강의 안내

R로 시작하는 데이터 시각화

이 강의는 R을 활용한 기술통계, 데이터 시각화와 선형회귀분석의 기본 원리 및 분석 절차를 다룹니다. 자료의 구조와 변수의 특성을 이해하고, 중심위치와 산포를 수치로 요약한 뒤 적절한 그래프로 표현합니다. 기본 R 함수로 분석의 개념을 익힌 다음, ggplot2로 시각화 방법을 확장하고 선형회귀모형을 이용하여 변수 간 관계를 설명하고 예측합니다.

제1장. 자료의 특성과 기술통계

범주형·이산형·연속형 변수의 차이를 정리하고, 평균·분산·표준편차·변동계수 등의 개념과 계산 방법을 살펴봅니다. 변수 유형별 기본 그래프와 가중평균, 그룹화 자료의 요약을 다룹니다. 이 장의 실습은 별도 패키지 없이 기본 R 함수로 진행합니다.

제1장 자료의 특성과 기술통계

제2장. ggplot2를 활용한 데이터 시각화

앞 장에서 다룬 분포와 관계를 ggplot2의 문법으로 표현합니다. 산점도, 막대그래프, 상자그림을 작성하고 색상·범례·테마·패널을 조정하며, 분석 결과를 파일로 저장합니다.

제2장 ggplot2를 활용한 데이터 시각화

제3장. 선형회귀분석

상관관계와 조건부 평균에서 출발하여 최소제곱법과 회귀계수의 의미를 살펴봅니다. lm()으로 모형을 적합하고 결정계수, 잔차, 예측 오차를 점검한 뒤, predict()로 평균의 신뢰구간과 개인의 예측구간을 구합니다. 아버지·아들 키 자료와 가상 스포츠 자료로 실습합니다.

제3장 선형회귀분석

제4장. 국민체력 100 자료를 이용한 종합 실습

train_R에 포함된 국민체력 100 표본 자료로 앞의 세 장을 종합적으로 적용합니다. 분석 대상을 정하고 결측값을 점검한 뒤, 기술통계와 기본 R 그래프, ggplot2 시각화, 단순선형회귀분석을 수행합니다. 상대악력과 윗몸말아올리기의 관계를 중심으로 12개 단계별 실습과 4개 종합 과제를 수행하고 분석 보고서를 작성합니다.

실습 환경과 진행 방법

실습에는 R과 RStudio를 사용합니다. 설치와 코드 실행 방법은 1장의 시작 부분에서 설명합니다. 웹 교재는 코드와 실행 결과를 함께 제시하며, 실습 코드는 각자의 RStudio 환경에서 실행합니다.

  1. 예제 전체를 실행해 같은 결과가 나오는지 확인합니다.
  2. 변수와 옵션을 변경하여 그래프에 미치는 영향을 확인합니다.
  3. 자료의 특성을 고려하여 결과를 해석합니다.
  4. 연습문제를 통해 분석 절차를 적용하고 해설과 비교합니다.
