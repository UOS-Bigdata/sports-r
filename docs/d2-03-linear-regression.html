제3장 선형회귀분석

앞 장에서는 산점도를 이용하여 두 변수 사이의 관계를 시각적으로 살펴보았습니다. 이 장에서는 그 관계를 수치로 요약하고, 설명변수의 값으로부터 반응변수의 평균과 새로운 관측값을 예측하는 선형회귀분석을 다룹니다. 설명변수가 하나인 단순선형회귀모형을 중심으로 분석 절차를 익힙니다.

아버지와 아들의 키 자료를 이용하여 상관계수, 최소제곱법, 회귀계수와 결정계수의 의미를 설명합니다. 이어서 R의 lm()으로 모형을 적합하고, 잔차를 점검한 뒤 predict()로 예측값과 구간을 계산합니다. 마지막에는 같은 절차를 스포츠 측정 자료에 적용합니다.

3.1 변수 간 관계와 분석 자료

3.1.1 설명변수와 반응변수

회귀분석에서는 분석 목적에 따라 변수의 역할을 구분합니다. 반응변수(response variable)는 설명하거나 예측하려는 변수이며, 설명변수(explanatory variable)는 그 예측에 이용하는 변수입니다. 일반적으로 설명변수를 \(x\), 반응변수를 \(y\)로 표시합니다.

분석 목적 설명변수 \(x\) 반응변수 \(y\)
아버지의 키로 아들의 키 예측 아버지의 키 아들의 키
악력으로 점프 높이 예측 악력 점프 높이
주간 훈련시간으로 경기기록 예측 주간 훈련시간 경기기록

변수의 역할은 자료의 열 순서가 아니라 분석 목적에 따라 정합니다. 예를 들어 악력과 점프 높이를 함께 측정했다고 해서 악력이 점프 높이의 원인이라고 결론 내릴 수는 없습니다. 체격, 성별, 연령, 훈련 수준 등 다른 요인도 관계에 관여할 수 있습니다.

3.1.2 실습 자료 불러오기

실습에는 첨부 교재에서 사용한 아버지·아들 키 자료를 사용합니다. 한 행은 한 쌍의 키를 나타내며, fheight는 아버지의 키, sheight는 아들의 키입니다. CSV 원본의 단위는 inch입니다.

인터넷에 공개된 CSV의 URL을 read.csv()에 전달하여 자료를 바로 불러옵니다. 인터넷에 연결된 상태에서 다음 코드를 실행합니다. CSV를 미리 내려받거나 자료를 읽기 위한 작업 폴더를 지정할 필요는 없습니다.

3.1.3 산점도와 상관계수

먼저 산점도를 그려 관계의 방향, 직선에 가까운 정도, 값이 크게 벗어난 관측값을 확인합니다. 점이 겹치는 부분은 alpha로 투명도를 조정합니다. 점선은 각 변수의 평균입니다.

ggplot(father_son, aes(x = fheight, y = sheight)) +
  geom_point(alpha = 0.3, color = "steelblue4") +
  geom_vline(xintercept = mean(father_son$fheight), linetype = "dashed") +
  geom_hline(yintercept = mean(father_son$sheight), linetype = "dashed") +
  labs(x = "아버지의 키 (cm)", y = "아들의 키 (cm)")

아버지의 키가 큰 쪽에서 아들의 키도 큰 경향이 나타납니다. 그러나 같은 아버지 키에 대해서도 아들의 키는 넓게 분포합니다. 관계가 있다는 것은 개별 관측값을 오차 없이 예측할 수 있다는 뜻은 아닙니다.

피어슨 상관계수(Pearson correlation coefficient)는 두 수치형 변수 사이의 선형 관계의 방향과 강도를 나타냅니다. 값은 \(-1\)과 \(1\) 사이에 있으며, 부호는 관계의 방향을, 절댓값은 직선에 가까운 정도를 나타냅니다.

\[ r = \frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})} {\sqrt{\sum_{i=1}^{n}(x_i-\bar{x})^2\sum_{i=1}^{n}(y_i-\bar{y})^2}} \]

r_height <- cor(father_son$fheight, father_son$sheight)
r_height
[1] 0.5013383

상관계수는 약 0.501으로 양의 선형 관계를 나타냅니다. 상관계수는 단위가 없는 수치이며, 두 키를 inch에서 cm로 변환해도 바뀌지 않습니다. 반면 회귀식의 기울기는 변수의 단위와 표준편차에 따라 달라집니다.

보충: 표준화한 값으로 상관계수 계산하기

1장에서 배운 평균과 표준편차를 이용하면 각 값을 표준화할 수 있습니다. R의 scale()은 기본적으로 평균을 빼고 표본표준편차로 나눕니다.

zx <- as.numeric(scale(father_son$fheight))
zy <- as.numeric(scale(father_son$sheight))
n <- nrow(father_son)

sum(zx * zy) / (n - 1)
[1] 0.5013383

표본표준편차의 분모가 \(n-1\)이므로 위의 계산에서도 \(n-1\)로 나눕니다. 결과는 cor()와 같습니다.

상관계수가 0에 가깝더라도 비선형 관계는 존재할 수 있습니다. 다음 자료에서는 \(y=x^2\)라는 명확한 관계가 있지만 상관계수는 0에 가깝습니다.

curve_data <- data.frame(x = seq(-3, 3, length.out = 61))
curve_data$y <- curve_data$x^2
round(cor(curve_data$x, curve_data$y), 10)
[1] 0
ggplot(curve_data, aes(x = x, y = y)) +
  geom_point(color = "steelblue4") +
  labs(x = "x", y = "y = x²")

또한 상관관계만으로 인과관계를 판단하지 않습니다. 예를 들어 기온은 아이스크림과 에어컨 판매량 모두에 영향을 줄 수 있습니다. 이런 제3의 변수는 인과관계를 해석할 때 교란변수(confounding variable)가 될 수 있습니다. 회귀계수를 계산해도 자료의 수집 방식과 다른 요인을 검토해야 한다는 점은 같습니다.

3.2 단순선형회귀모형과 최소제곱법

3.2.1 개별 관측값과 조건부 평균

단순선형회귀모형은 설명변수 \(x\)가 주어졌을 때 반응변수 \(Y\)의 조건부 평균을 직선으로 나타냅니다.

\[ E(Y\mid x)=\beta_0+\beta_1x \]

\(E(Y\mid x)\)는 설명변수가 특정 값 \(x\)일 때의 반응변수 평균을 뜻합니다. \(\beta_0\)는 절편, \(\beta_1\)은 기울기입니다. 실제 관측값은 평균 주위에 흩어져 있으므로 다음과 같이 오차항을 포함하여 표현합니다.

\[ Y_i=\beta_0+\beta_1x_i+\varepsilon_i,\qquad E(\varepsilon_i\mid x_i)=0 \]

기호 의미
\(\beta_0\) \(x=0\)일 때 반응변수의 평균을 나타내는 절편
\(\beta_1\) \(x\)가 1단위 다를 때 반응변수 평균의 차이를 나타내는 기울기
\(\varepsilon_i\) 실제 관측값이 모형의 평균에서 벗어나는 정도인 오차항

아버지의 키를 구간으로 나누어 각 구간의 평균을 구하면 조건부 평균의 의미를 살펴볼 수 있습니다. 아래에서는 각 구간의 아버지 평균 키와 아들 평균 키를 함께 계산합니다.

father_son$height_band <- cut(
  father_son$fheight,
  breaks = c(140, 160, 170, 180, 200), include.lowest = TRUE
)
band_means <- aggregate(
  cbind(fheight, sheight) ~ height_band,
  data = father_son, FUN = mean
)
band_counts <- aggregate(sheight ~ height_band, data = father_son, FUN = length)
band_means$n <- band_counts$sheight[match(band_means$height_band,
                                         band_counts$height_band)]
band_means
  height_band  fheight  sheight   n
1   [140,160] 157.0334 167.0005  48
2   (160,170] 165.9806 171.1997 372
3   (170,180] 174.5800 175.9168 521
4   (180,200] 183.1884 180.3671 137
ggplot(father_son, aes(x = fheight, y = sheight)) +
  geom_point(alpha = 0.15, color = "grey40") +
  geom_point(data = band_means, aes(size = n), color = "firebrick") +
  labs(x = "아버지의 키 (cm)", y = "아들의 키 (cm)", size = "구간별 관측 수")

붉은 점은 키 구간별 평균이며, 특정한 한 아들의 키를 나타내지 않습니다. 구간별 평균은 구간의 경계와 관측 수에 따라 달라집니다. 이후 회귀식은 이 네 개의 평균점이 아니라 전체 1,078개 관측값을 사용하여 적합합니다.

3.2.2 잔차와 최소제곱법

자료로부터 추정한 회귀식을 \(\hat{y}_i=\hat{\beta}_0+\hat{\beta}_1x_i\)로 나타냅니다. 기호 위의 모자는 자료를 이용하여 구한 추정값임을 뜻합니다. 관측값 \(y_i\)와 적합값 \(\hat{y}_i\)의 차이를 잔차(residual)라고 합니다.

\[ e_i=y_i-\hat{y}_i \]

오차항 \(\varepsilon_i\)는 알 수 없는 모평균으로부터의 차이이고, 잔차 \(e_i\)는 자료에서 추정한 회귀직선으로부터의 차이입니다. 잔차가 양수이면 관측값이 직선 위쪽에, 음수이면 아래쪽에 있습니다.

최소제곱법(ordinary least squares)은 잔차제곱합이 가장 작아지는 절편과 기울기를 찾는 방법입니다. 여기서 거리는 각 관측점에서 직선까지의 수직 방향, 즉 반응변수 방향의 차이입니다.

\[ \mathrm{SSE}=\sum_{i=1}^{n}e_i^2 =\sum_{i=1}^{n}\{y_i-(\hat{\beta}_0+\hat{\beta}_1x_i)\}^2 \]

관측 수가 같은 자료에서는 \(\mathrm{MSE}=\mathrm{SSE}/n\)을 최소화해도 같은 회귀식을 얻습니다. 차이를 제곱하면 양수와 음수가 상쇄되지 않으며, 큰 차이에 더 큰 가중치가 부여됩니다.

3.2.3 회귀계수 직접 계산하기

절편을 포함하는 단순선형회귀에서 설명변수의 분산이 0이 아니면 최소제곱 추정값은 다음과 같습니다.

\[ \hat{\beta}_1= \frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})} {\sum_{i=1}^{n}(x_i-\bar{x})^2} =r\frac{s_y}{s_x}, \qquad \hat{\beta}_0=\bar{y}-\hat{\beta}_1\bar{x} \]

\(s_x\)와 \(s_y\)는 각각 설명변수와 반응변수의 표본표준편차입니다. 다음 코드는 이 식을 그대로 계산합니다.

x <- father_son$fheight
y <- father_son$sheight

b1 <- sum((x - mean(x)) * (y - mean(y))) / sum((x - mean(x))^2)
b0 <- mean(y) - b1 * mean(x)

c(intercept = b0, slope = b1)
intercept     slope 
86.071975  0.514093 
cor(x, y) * sd(y) / sd(x)  # 같은 기울기를 구하는 다른 식
[1] 0.514093

기울기는 약 0.514, 절편은 약 86.072입니다. 기울기와 상관계수는 부호가 같지만 일반적으로 값이 같지는 않습니다. 두 변수의 표준편차가 같으면 기울기와 상관계수가 일치합니다.

서로 다른 두 후보 직선과 최소제곱 직선의 MSE를 비교합니다. mean() 안에서 각 관측값과 직선의 차이를 제곱하여 평균을 구합니다.

data.frame(
  line = c("20 + 0.8x", "25 + 0.9x", "최소제곱 직선"),
  MSE = c(
    mean((y - (20 + 0.8 * x))^2),
    mean((y - (25 + 0.9 * x))^2),
    mean((y - (b0 + b1 * x))^2)
  )
)
           line       MSE

보충: 최소제곱 공식의 유도

\(S(b_0,b_1)=\sum_i(y_i-b_0-b_1x_i)^2\)를 각각의 계수로 미분하여 0으로 놓습니다.

\[ \frac{\partial S}{\partial b_0}=-2\sum_i(y_i-b_0-b_1x_i)=0, \qquad \frac{\partial S}{\partial b_1}=-2\sum_ix_i(y_i-b_0-b_1x_i)=0 \]

첫 번째 식에서 \(b_0=\bar{y}-b_1\bar{x}\)를 얻습니다. 이를 두 번째 식에 대입하고 정리하면 \(b_1=\sum_i(x_i-\bar{x})(y_i-\bar{y})/\sum_i(x_i-\bar{x})^2\)가 됩니다. 설명변수에 변동이 있으면 이 해는 유일한 최소값을 줍니다.

3.3 R을 이용한 모형 적합과 결과 해석

3.3.1 lm()으로 회귀식 적합하기

R에서는 기본 제공 함수인 lm()으로 선형회귀모형을 적합합니다. lm()을 사용하기 위해 별도 패키지를 설치할 필요는 없습니다.

fit_height <- lm(sheight ~ fheight, data = father_son)
coef(fit_height)
(Intercept)     fheight 
  86.071975    0.514093

sheight ~ fheight에서 ~의 왼쪽은 반응변수, 오른쪽은 설명변수입니다. data = father_son은 변수들이 들어 있는 데이터프레임을 지정합니다. 절편은 기본으로 포함되며, fit_height에 적합한 모형이 저장됩니다. coef()는 추정한 회귀계수를 꺼내는 함수입니다.

출력 이름 의미
(Intercept) 절편 \(\hat{\beta}_0\)
fheight 아버지 키에 대한 기울기 \(\hat{\beta}_1\)

추정한 회귀식은 다음과 같습니다. 두 키의 단위는 모두 cm입니다.

\[ \widehat{\text{아들의 키}} =86.07198+0.51409\times\text{아버지의 키} \]

이 자료에서 아버지의 키가 1 cm 큰 경우, 모형이 추정한 아들의 평균 키는 약 0.514 cm 큽니다. 특정 아들의 키가 반드시 0.514 cm 커진다는 의미는 아닙니다. 절편 86.072는 식에서 \(x=0\)일 때의 값이지만, 아버지 키 0 cm는 관측 범위와 해석 가능한 대상에서 벗어나므로 실질적인 의미를 부여하지 않습니다.

계산에는 반올림한 회귀식 대신 coef() 또는 predict()의 값을 사용합니다. 기울기의 반올림 오차도 큰 \(x\)에 곱해지면 예측값의 차이로 나타날 수 있습니다.

3.4 모형 평가와 잔차 진단

3.4.1 MSE, RMSE와 결정계수

모형의 적합 정도는 잔차의 크기와 반응변수의 전체 변동을 함께 고려하여 평가합니다. 이 장에서는 적합 자료의 평균제곱오차를 \(\mathrm{MSE}=\mathrm{SSE}/n\)으로 정의하고, 그 제곱근을 RMSE라고 부릅니다.

\[ \mathrm{RMSE}=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}, \qquad R^2=1-\frac{\mathrm{SSE}}{\mathrm{SST}}, \qquad \mathrm{SST}=\sum_{i=1}^{n}(y_i-\bar{y})^2 \]

SST는 모든 관측값을 하나의 평균 \(\bar{y}\)로 예측할 때의 제곱오차합입니다. SSE는 회귀식으로 예측할 때의 제곱오차합입니다. 따라서 결정계수 \(R^2\)는 평균만 사용하는 것과 비교하여 회귀식이 관측된 변동을 얼마나 줄여 설명하는지 나타냅니다.

n <- nrow(father_son)
SSE <- sum(resid(fit_height)^2)
SST <- sum((father_son$sheight - mean(father_son$sheight))^2)
MSE <- SSE / n
RMSE <- sqrt(MSE)
R2 <- 1 - SSE / SST

c(MSE = MSE, RMSE = RMSE, R_squared = R2)
       MSE       RMSE  R_squared 
38.2308245  6.1831080  0.2513401 
summary(fit_height)$r.squared
[1] 0.2513401
cor(father_son$fheight, father_son$sheight)^2
[1] 0.2513401

이 자료에서 RMSE는 약 6.18 cm, 결정계수는 약 0.251입니다. 아들 키의 표본 내 변동 중 약 25.1%가 아버지 키를 이용한 회귀식으로 설명됩니다. 이를 예측 정확도가 25.1%라거나, 유전의 영향을 그 비율만큼 측정했다고 해석하지 않습니다.

절편을 포함한 일반적인 최소제곱 회귀에서 적합 자료의 \(R^2\)는 0과 1 사이입니다. 또한 절편을 포함하는 단순선형회귀에서 동일한 관측값으로 계산하면 \(R^2=r^2\)입니다. 절편을 제외하거나 새로운 평가 자료에서 계산한 결정계수에는 이 성질이 그대로 적용되지 않습니다.

MSE는 반응변수 단위의 제곱이고 RMSE는 반응변수와 같은 단위입니다. 모형을 비교할 때에는 같은 반응변수와 같은 평가 자료를 사용하는 것이 기본입니다. 서로 다른 모집단에서 얻은 \(R^2\)의 크기만으로 어느 모형이 더 유용한지 판단하지 않습니다.

계산상의 구분: MSE, 표본분산, 잔차표준오차

R의 var(y)는 분모가 \(n-1\)인 표본분산입니다. 따라서 위에서 정의한 MSE를 그대로 var(y)로 나눈 1 - MSE / var(y)는 정확한 결정계수가 아닙니다. SSE / SST를 사용하면 분모의 차이로 인한 혼동을 피할 수 있습니다.

또한 summary(lm())의 잔차표준오차는 이 모형에서 두 계수를 추정한 것을 반영하여 \(\sqrt{\mathrm{SSE}/(n-2)}\)로 계산합니다. RMSE의 분모 \(n\)과 구분합니다. 회귀분석의 분산분석표에서는 \(\mathrm{SSE}/(n-2)\)도 잔차평균제곱 또는 MSE라고 부르므로 문맥과 분모를 확인해야 합니다.

c(
  RMSE = sqrt(SSE / n),
  residual_standard_error = sqrt(SSE / (n - 2)),
  summary_sigma = summary(fit_height)$sigma
)

3.4.2 잔차 그래프와 모형의 가정

회귀식과 결정계수를 구한 뒤에는 직선 모형이 자료의 관계를 충분히 표현하는지 점검합니다. 통상적인 표준오차, 검정 및 구간 추론은 다음의 가정과 관련됩니다.

가정 또는 조건 의미와 점검 방법
선형성 및 조건부 평균 0인 오차 반응변수의 조건부 평균이 직선으로 표현되는지, 잔차에 체계적인 곡선이 남는지 확인합니다.
오차의 독립성 사람·가족·팀별 군집이나 반복 측정이 있는지 자료 수집 과정을 확인합니다.
등분산성 설명변수의 값에 따라 오차의 분산이 크게 달라지지 않는지 확인합니다.
오차의 정규성 정규 Q-Q 그림으로 크게 벗어나는 양상을 확인합니다. 정규오차 가정은 통상적인 소표본 t 검정과 예측구간의 근거입니다.

설명변수 자체가 정규분포를 따라야 하는 것은 아닙니다. 또한 잔차 그래프만으로 독립성이나 인과관계를 확인할 수는 없습니다. 이 CSV에는 가족 식별자나 상세한 표집 정보가 없으므로 관련 조건은 자료만으로 충분히 검증할 수 없습니다.

먼저 적합값에 대한 잔차를 그립니다. 점들이 0을 중심으로 퍼지는지, 곡선이나 깔때기 형태가 나타나는지 확인합니다.

ggplot(height_result, aes(x = fitted_cm, y = residual_cm)) +
  geom_point(alpha = 0.3, color = "steelblue4") +
  geom_hline(yintercept = 0, color = "firebrick", linetype = "dashed") +
  labs(x = "적합값 (cm)", y = "잔차 (cm)")

잔차에 뚜렷한 곡선이 남으면 직선 외의 관계를 검토하고, 잔차의 퍼짐이 달라지면 통상적인 표준오차와 예측구간이 적절한지 검토합니다. 이런 양상이 없다는 것만으로 모든 가정이 충족되었다고 결론 내리지는 않습니다.

정규 Q-Q 그림은 표준화 잔차와 정규분포의 이론적 분위수를 비교합니다.

residual_data <- data.frame(standardized = rstandard(fit_height))
ggplot(residual_data, aes(sample = standardized)) +
  stat_qq(alpha = 0.4, color = "steelblue4") +
  stat_qq_line(color = "firebrick") +
  labs(x = "정규분포의 이론적 분위수", y = "표준화 잔차")

가운데 부분이 직선에 가깝더라도 양쪽 꼬리에서 벗어나는 관측값이 있는지 확인합니다. 큰 잔차가 나타나는 경우 입력 오류와 특수한 관측 조건을 먼저 살펴봅니다. 그래프를 직선에 맞추기 위해 관측값을 임의로 제외하지 않습니다.

3.4.3 새로운 자료에서의 예측 오차

지금까지의 MSE는 모형을 만드는 데 사용한 자료에서 계산한 값입니다. 예측 성능을 평가할 때에는 모형 적합에 쓰지 않은 자료의 오차도 확인해야 합니다. 다음은 자료의 약 80%로 모형을 적합하고 나머지 약 20%로 평가하는 기본 예제입니다.

set.seed(2026)
train_id <- sample(seq_len(nrow(father_son)),
                   size = floor(0.8 * nrow(father_son)))
train_data <- father_son[train_id, ]
test_data <- father_son[-train_id, ]

fit_train <- lm(sheight ~ fheight, data = train_data)
test_pred <- predict(fit_train, newdata = test_data)

c(
  train_RMSE = sqrt(mean(resid(fit_train)^2)),
  test_RMSE = sqrt(mean((test_data$sheight - test_pred)^2))
)
train_RMSE  test_RMSE 
  6.219054   6.042185

set.seed()는 같은 무작위 분할을 재현하기 위한 설정입니다. 한 번의 분할 결과는 우연에 따라 달라질 수 있으며, 평가 RMSE가 항상 학습 RMSE보다 크지는 않습니다. 실제 자료에 같은 사람의 반복 측정이나 가족·팀별 군집이 있으면 그 단위가 양쪽에 섞이지 않도록 나눠야 합니다. 시간 순서가 중요한 예측에서는 과거로 학습하고 이후 시점으로 평가합니다. 여기서는 무작위 분할의 계산 절차를 익히는 데 목적을 둡니다.

3.5.2 평균의 신뢰구간과 개인의 예측구간

같은 설명변수 값에서도 평균을 추정하는 문제와 새로운 관측값 하나를 예측하는 문제는 구분됩니다.

구분 대상 R의 옵션
평균반응의 신뢰구간 아버지 키가 185 cm인 집단의 아들 평균 키 interval = "confidence"
새로운 관측값의 예측구간 아버지 키가 185 cm인 새로운 한 아들의 키 interval = "prediction" 
predict(fit_height, newdata = new_father,
        interval = "confidence", level = 0.95)
       fit      lwr      upr
1 181.1792 180.3928 181.9655
predict(fit_height, newdata = new_father,
        interval = "prediction", level = 0.95)
       fit      lwr      upr
1 181.1792 169.0102 193.3482

출력의 fit은 점예측값, lwr와 upr는 각각 구간의 하한과 상한입니다. 두 구간의 중심은 같지만 개인의 예측구간이 더 넓습니다. 예측구간은 평균 회귀식의 추정 불확실성과 새로운 관측값의 개별 변동을 모두 반영하기 때문입니다.

95% 예측구간은 모형과 자료 생성 조건이 적절할 때, 같은 방식으로 새로운 관측값과 구간을 반복하여 얻으면 약 95%의 구간이 해당 새로운 관측값을 포함하도록 구성한 구간입니다. 모든 관측값이 반드시 들어가는 범위는 아닙니다.

관측 범위 안의 여러 아버지 키에 대해 두 구간을 함께 그리면 차이가 분명해집니다.

height_grid <- data.frame(
  fheight = seq(min(father_son$fheight), max(father_son$fheight), length.out = 100)
)
mean_ci <- predict(fit_height, newdata = height_grid, interval = "confidence")
individual_pi <- predict(fit_height, newdata = height_grid, interval = "prediction")
height_grid$fit <- mean_ci[, "fit"]
height_grid$mean_lower <- mean_ci[, "lwr"]
height_grid$mean_upper <- mean_ci[, "upr"]
height_grid$individual_lower <- individual_pi[, "lwr"]
height_grid$individual_upper <- individual_pi[, "upr"]

ggplot(height_grid, aes(x = fheight)) +
  geom_ribbon(aes(ymin = individual_lower, ymax = individual_upper,
                  fill = "개인 예측구간"), alpha = 0.35) +
  geom_point(data = father_son, aes(y = sheight), alpha = 0.15, size = 1) +
  geom_ribbon(aes(ymin = mean_lower, ymax = mean_upper,
                  fill = "평균 신뢰구간"), alpha = 0.8) +
  geom_line(aes(y = fit), color = "steelblue4", linewidth = 0.8) +
  scale_fill_manual(values = c("개인 예측구간" = "grey65",
                                "평균 신뢰구간" = "skyblue3")) +
  labs(x = "아버지의 키 (cm)", y = "아들의 키 (cm)", fill = "95% 구간") +
  theme(legend.position = "bottom")

앞 장의 geom_smooth(method = "lm")에서 기본으로 표시하는 음영은 평균반응에 대한 신뢰구간입니다. 개인의 예측구간으로 해석해서는 안 됩니다.

3.5.3 외삽과 적용 범위

예측 전에 설명변수가 관측된 범위를 확인합니다.

range(father_son$fheight)
[1] 149.8803 191.6022

관측 범위를 벗어난 설명변수에 대해 예측하는 것을 외삽(extrapolation)이라고 합니다. predict()는 그런 값에도 수치를 반환할 수 있지만, 관측 범위 밖에서도 같은 직선 관계가 유지된다는 근거는 별도로 필요합니다. 프로그램이 값을 계산했다는 사실만으로 예측의 타당성이 확보되지는 않습니다.

또한 이 자료로 얻은 회귀식을 다른 시대, 지역, 연령 또는 측정 조건의 집단에 그대로 적용할 수 있는지는 별도의 문제입니다. 회귀식과 함께 분석 대상, 변수의 단위, 관측 범위, 예측의 불확실성을 기록합니다.
