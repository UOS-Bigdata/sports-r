데이터 불러오기

실습 데이터 준비

source("data/practice_data.R")
객체 행 수 내용
fitness 30 체력측정 원자료 (성인 22건 + 어르신 8건)

source()는 R 스크립트 파일을 통째로 실행하는 함수임. practice_data.R 안에 데이터를 만드는 코드가 들어 있어서, 실행하면 Environment 창에 두 데이터프레임이 생김. 국민체력100 측정 자료와 비슷한 구조로 만든 가상 데이터이며, 1교시에 직접 만든 member는 fitness의 앞 10명과 같음.

한글 깨짐

Windows에서 엑셀로 저장한 CSV는 인코딩이 CP949인 경우가 많음. 한글이 깨지면 read.csv("파일.csv", fileEncoding = "CP949") 또는 fileEncoding = "UTF-8"을 지정해서 다시 불러옴. 공공데이터포털 등에서 내려받은 CSV도 인코딩을 먼저 확인하는 것이 좋음.

진짜 NA 성인의 chair_stand, 어르신의 shuttle O

is.na()는 R이 진짜 NA로 저장한 값만 찾아냄. 여기서 잡힌 60개는 모두 “해당 연령 단계에서 측정하지 않는 항목”임. 측정 거부나 입력 오류를 뜻하는 -9, 999 같은 코드는 R 입장에서는 정상적인 숫자이므로 is.na()로 찾을 수 없고, 그대로 두면 평균 등이 왜곡됨. 어떤 값이 결측 코드인지는 반드시 코드북(자료 설명서)에서 확인해야 함.

결측 코드를 NA로 바꾸기

fit <- fitness                                   # 원자료는 그대로 두고 복사본에서 작업
fit$age[fit$age %in% c(-9, 999)]     <- NA
fit$grip[fit$grip %in% c(-1, 999)]   <- NA
fit$shuttle[fit$shuttle == -1]       <- NA
fit$sex[fit$sex == "미상"]           <- NA
fit$exercise[fit$exercise == ""]     <- NA
fit$grade[fit$grade == "측정중단"]   <- NA

colSums(is.na(fit))
         id       stage         sex         age      center      region 
          0           0           1           2           0           0 
   exercise      height      weight     fat_pct        grip       situp 
          1           0           0           0           2           8 
  sit_reach     shuttle chair_stand   walk_2min       grade 
          0           9          22          22           1

fit$age[조건] <- NA는 “age 열에서 조건이 TRUE인 위치에 NA를 넣어라”라는 뜻으로, 1교시 벡터 조건 인덱싱(grip[grip > 40])에 값을 넣는 방식임. 원자료(fitness)를 보존하기 위해 복사본(fit)에서 작업함. 이후 실습은 모두 정리된 fit을 사용함.

조심

na.rm = TRUE는 결측을 빼고 계산하라는 뜻임. fit에는 측정하지 않는 항목(연령 단계별)과 결측 코드에서 바뀐 NA가 함께 있으므로, 평균을 구할 때 na.rm = TRUE가 자주 필요함. na.omit(fit)은 어느 열이든 결측이 하나라도 있는 행을 통째로 지우는데, 이 데이터에서는 모든 행에 해당 없는 항목의 NA가 있어서 0행이 됨. 필요한 열만 고른 뒤에 적용해야 함.

df$새열이름 <- 값 형태로 쓰면 열이 추가됨. 이미 있는 열 이름을 쓰면 그 열이 덮어써짐. 열끼리의 계산은 같은 행끼리 이루어지므로(1교시 벡터 연산), 측정자마다 BMI와 상대악력이 한 번에 계산됨.

               ifelse(fit$bmi < 23,   "정상",

ifelse(조건, 참일 때 값, 거짓일 때 값)을 겹쳐 쓰면 여러 구간으로 나눌 수 있음. 18.5 / 23 / 25는 아시아-태평양 기준 BMI 구간임. cut()은 숫자를 구간으로 나누는 함수로, breaks는 구간 경계임(c(18, 39, 64, Inf)는 (18, 39], (39, 64], (64, ∞) 세 구간). cut()의 결과는 팩터이므로 순서가 자동으로 유지됨. useNA = "ifany"는 NA도 빈도표에 함께 보여 달라는 뜻임(나이가 결측인 2명). 오후에는 같은 작업을 case_when()으로 더 읽기 쉽게 함.
