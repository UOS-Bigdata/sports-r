집단별 요약

group_by() + summarize()

summarize() — 여러 행을 한 행으로

fit %>%
  summarize(
    n         = n(),
    mean_grip = mean(grip, na.rm = TRUE),
    sd_grip   = sd(grip, na.rm = TRUE),
    max_flex  = max(sit_reach)
  )
# A tibble: 1 × 4
      n mean_grip sd_grip max_flex
  <int>     <dbl>   <dbl>    <dbl>
1    30     30.79   8.963     17.2

summarize()(또는 summarise())는 데이터 전체를 요약해서 한 행짜리 표를 만듦. 이름 = 요약 함수 형태로 여러 개를 동시에 쓸 수 있음. n()은 행 개수를 세는 함수로 summarize(), mutate(), filter() 안에서만 쓸 수 있음. 악력에는 결측(NA)이 있으므로 na.rm = TRUE가 필요함.

group_by() + summarize()

fit %>%
  group_by(stage) %>%
  summarize(n = n(), mean_grip = mean(grip, na.rm = TRUE))
# A tibble: 2 × 3
  stage      n mean_grip
  <chr>  <int>     <dbl>
1 성인      22     32.79
2 어르신     8     25.79

group_by()는 데이터를 집단으로 나눠 두기만 하고 실제 계산은 하지 않음. 그 뒤의 summarize()가 집단마다 따로 계산해서 집단당 한 행으로 줄임. 오전에 mean(fit$grip[fit$sex == "F"], na.rm = TRUE)처럼 집단마다 반복하던 계산을 한 번에 처리함.

요약 함수 모음

fit %>%
  group_by(stage) %>%
  summarize(
    n          = n(),                                  # 인원
    mean_age   = mean(age, na.rm = TRUE),              # 평균
    med_grip   = median(grip, na.rm = TRUE),           # 중앙값
    q90_flex   = quantile(sit_reach, 0.9),             # 90분위수
    top_n      = sum(grade %in% c("1등급", "2등급")),  # 1·2등급 인원
    top_rate   = mean(grade %in% c("1등급", "2등급")), # 1·2등급 비율
    obese_rate = mean(bmi >= 25),                      # BMI 25 이상 비율
    n_center   = n_distinct(center)                    # 측정 센터 수
  )
# A tibble: 2 × 9
  stage      n mean_age med_grip q90_flex top_n top_rate obese_rate n_center
  <chr>  <int>    <dbl>    <dbl>    <dbl> <int>    <dbl>      <dbl>    <int>
1 성인      22    43.5      32.3    15.69     8   0.3636     0.4091        4
2 어르신     8    72.38     24.7    13.95     4   0.5        0.375         4

1교시에서 다룬 “조건식 + sum() = 개수, 조건식 + mean() = 비율”이 여기서 자주 쓰임. n_distinct()는 중복을 뺀 값의 개수임. %in%은 NA를 FALSE로 처리하므로 등급이 결측인 사람은 1·2등급이 아닌 것으로 계산됨.

두 개 이상의 집단 변수

  • 집단 변수의 조합마다 한 행
  • sex가 NA인 사람은 별도 집단(NA)으로 나옴
  • .groups = "drop" : 요약 후 그룹 해제

.groups를 쓰지 않으면 마지막 집단 변수(sex)만 풀리고 stage로는 여전히 묶인 상태로 남으며, “summarise() has grouped output by ‘stage’”라는 안내 메시지가 나옴. 이후 작업에서 예상치 못한 결과가 나올 수 있으므로 .groups = "drop"을 붙이거나 ungroup()으로 풀어 주는 것이 안전함. 체력 기준은 연령 단계·성별로 다르기 때문에, 체력측정 자료에서는 이렇게 두 변수로 묶어 요약하는 경우가 많음.

dplyr 1.1.0부터는 group_by() 없이 summarize(..., .by = 열)로 그 자리에서만 묶을 수 있음. 결과는 항상 그룹이 풀린 상태로 나오므로 .groups를 신경 쓰지 않아도 됨. 단, 결과가 집단 순서대로 정렬되지 않고 데이터에 처음 나온 순서대로 나옴.

여러 열을 한 번에 요약 — across()

fit %>%
  group_by(stage) %>%
  summarize(across(c(grip, sit_reach, fat_pct), ~ mean(.x, na.rm = TRUE)))

fit %>%
  group_by(stage) %>%
  summarize(across(c(grip, sit_reach),
                   list(평균 = ~ mean(.x, na.rm = TRUE), 표준편차 = ~ sd(.x, na.rm = TRUE))))
# A tibble: 2 × 5

2 어르신     25.79         4.493          5.85               6.701

~ mean(.x, na.rm = TRUE)는 “각 열(.x)의 평균을 결측을 빼고 구하라”는 짧은 함수임. list(평균 = ..., 표준편차 = ...)처럼 함수 여러 개를 이름과 함께 주면 열이름_함수이름 형태의 열이 만들어짐. 측정 항목별 평균·표준편차 표를 만들 때 유용함.

두 번째 코드는 연령 단계 안에서의 운동 빈도 구성비(행 비율)를 구함. group_by(stage) 후 mutate()를 쓰면 sum(n)이 연령 단계마다 따로 계산되기 때문임. 이처럼 group_by() 뒤에 mutate()를 쓰면 행 수는 그대로 두고 집단별 계산 결과를 각 행에 붙임.

집단 안에서 mutate()

fit %>%
  group_by(stage, sex) %>%
  mutate(
    grp_mean = mean(grip, na.rm = TRUE),   # 같은 연령 단계·성별 평균 악력
    diff     = grip - grp_mean,            # 평균과의 차이
    rank_grp = min_rank(desc(grip))        # 같은 집단 안 순위
  ) %>%
  ungroup() %>%
  select(id, stage, sex, grip, grp_mean, diff, rank_grp) %>%
  arrange(stage, sex, rank_grp)

데이터 결합

bind_rows() · _join()

표가 나뉘어 있는 이유와 키

  • 측정 결과와 프로그램 참여 기록은 한 행의 단위가 다름 (한 사람이 프로그램에 여러 번 참여 가능)
  • 그래서 단위별로 표를 나누고, 키(key) 열로 연결
  • 분석할 때 필요한 표끼리 다시 합침 → 결합(join)

참여 기록을 측정 결과 표에 그대로 넣으면, 프로그램에 두 번 참여한 사람은 측정 결과가 두 번 반복되어 저장됨. 이런 중복을 피하려고 단위별로 표를 나누고, 두 표를 연결하는 열(키)을 둠. 여기서는 측정 번호 id가 키임.

위아래로 붙이기 — bind_rows()

  select(-situp, -shuttle)               # 어르신 측정 항목만

실제 자료는 연령 단계별로 측정 항목이 달라 파일이 따로 제공되는 경우가 많음. 여기서는 fit을 성인·어르신 파일로 나눈 뒤 다시 붙여서 그 상황을 재현함. bind_rows()는 열 이름을 기준으로 행을 이어 붙이고, 한쪽에만 있는 열은 다른 쪽 행에서 NA로 채움. 이때의 NA는 측정 거부가 아니라 “해당 연령 단계 측정 항목이 아님”이라는 뜻임.

참고

bind_cols()는 두 표를 옆으로 붙이는데, 행 순서가 정확히 같다고 가정하고 그대로 붙임. 순서가 다르면 엉뚱한 사람의 값이 붙어도 오류가 나지 않으므로, 옆으로 붙일 때는 키를 기준으로 하는 _join()을 쓰는 것이 안전함.

옆으로 붙이기 — _join() 종류

함수 남는 행 열
left_join(x, y) x의 모든 행 x + y
inner_join(x, y) 키가 양쪽에 모두 있는 행 x + y
full_join(x, y) 양쪽의 모든 행 x + y
right_join(x, y) y의 모든 행 x + y
semi_join(x, y) y에 키가 있는 x의 행 x만
anti_join(x, y) y에 키가 없는 x의 행 x만

짝이 없는 쪽의 열은 NA로 채워짐. 실무에서는 기준 표를 그대로 두고 정보를 덧붙이는 left_join()을 가장 많이 씀.

inner_join() vs left_join()

programs %>%
  left_join(fit, by = "id") %>%
  nrow()
[1] 15
programs %>%
  inner_join(fit, by = "id") %>%
  nrow()
[1] 13
  • left_join() : 참여 기록 15건 모두 유지, 짝 없는 2건은 NA
  • inner_join() : 짝이 있는 13건만 남음 → 조용히 행이 사라질 수 있음
확인

결합 전후로 nrow()를 확인하는 습관을 들여야 함. inner_join()은 짝이 없는 행을 아무 경고 없이 버리기 때문에, 분석 대상이 줄어든 것을 모르고 지나치기 쉬움.

age %/% 10 * 10은 나이를 10으로 나눈 몫에 10을 곱해 10세 단위 연령대(20, 30, … 70)를 만드는 식임. 상대악력과 앉아윗몸앞으로굽히기는 두 연령 단계에 공통으로 있는 항목이어서 나이에 따른 변화를 이어서 볼 수 있음. 연령 단계별 고유 항목(교차윗몸일으키기, 의자에앉았다일어서기 등)은 해당 단계 안에서만 비교함. 표본이 30명이라 집단별 인원이 매우 적다는 점에 유의.

  2. 연령 단계 · 성별 평균 상대악력과 평균 체지방률
  3. 센터별 어르신 측정 비율(%)을 구하고 비율이 높은 순으로 정렬
  4. 연령 단계별 등급 구성비(%)
  5. 어르신 중 의자에앉았다일어서기(chair_stand)가 같은 성별 평균보다 높은 사람의 비율
