2일차 장별 구성과 권장 진행 순서는 2일차 강의 안내에 있음.

실습 파일 내려받기

1일차

파일 내용
day1-data.zip 1일차 실습 파일 묶음 (아래 두 파일)
practice_data.R 실습 데이터 생성 스크립트. source("data/practice_data.R")로 실행하면 fitness(30행), programs(15행)가 만들어짐
fitness.csv 2교시 read.csv() 불러오기 실습용 CSV (fitness와 같은 내용)

1일차 데이터는 국민체력100 체력측정 자료와 비슷한 구조로 만든 가상 데이터이며 실제 측정 결과와 무관함. 1교시에 직접 입력하는 member(10명)는 fitness의 앞 10명과 같음.

2일차

파일 내용
day2-data.zip 2일차 실습 데이터 묶음 (아래 세 CSV와 설명 파일)
sports100-practice.csv 제4장 국민체력 100 표본 자료 (2,000행)
sports100-variables.csv 제4장 변수 설명
father-and-son.csv 제3장 아버지·아들 키 자료 (본문 코드는 인터넷 주소에서 직접 읽음)

장별 R Markdown 원고와 R 실습 코드는 2일차 강의 안내의 “실습 파일”에서 내려받을 수 있음.

폴더 구성

내려받은 파일은 RStudio 프로젝트 폴더 안에 data 폴더를 만들어 저장함. 코드의 data/파일이름 경로가 이 폴더를 가리킴.

준비 사항

  1. R 설치 (https://cran.r-project.org) → RStudio 설치 (https://posit.co/download/rstudio-desktop/) 순서로 설치
  2. RStudio 콘솔에서 아래 패키지 설치 (최초 1회)
install.packages(c("dplyr", "ggplot2"))

1일차 슬라이드 사용법

키 기능
→ ← / Space 다음·이전 슬라이드
F 전체 화면
S 발표자 화면 (노트와 다음 슬라이드 미리보기)
C / B 슬라이드 위에 판서 / 칠판 화면
M 메뉴 (슬라이드 목록)
Esc / O 전체 슬라이드 한눈에 보기
Alt + 클릭 해당 부분 확대

실습 슬라이드의 타이머는 클릭하면 시작·정지, 더블클릭하면 초기화됨.

PDF

각 문서를 화면 그대로 PDF로 저장한 파일임. 탭과 보충 상자는 모두 펼쳐서 넣었고, 실습 정답과 과제 해설은 넣지 않았음. 문서를 브라우저에서 열고 Cmd + P(Windows: Ctrl + P) → “PDF로 저장”을 선택해도 같은 결과가 나옴(배경 그래픽 옵션 켜기).
