제4장 국민체력 100 자료를 이용한 종합 실습

이 장에서는 train_R의 「국민체력 100 자료를 이용한 데이터 분석 예제」에 포함된 측정 자료를 이용하여 앞의 세 장을 종합적으로 실습합니다. 기술통계로 자료의 특성을 요약하고, 기본 R 그래프와 ggplot2로 분포와 관계를 확인한 뒤, 선형회귀모형으로 관계를 설명하고 예측합니다.

중심 분석 질문은 “청소년의 상대악력이 높을수록 윗몸말아올리기 횟수도 많은가?”입니다. 분석 대상과 변수의 단위를 먼저 정하고, 결측값 처리에 따라 표본 수가 어떻게 달라지는지 기록합니다. 각 절의 실습을 순서대로 실행한 뒤 마지막의 종합 과제를 수행합니다.

4.1.2 원자료와 실습 파일

원자료는 train_R에 포함된 sample_data_sports100.xlsx와 column_info.xlsx입니다. 실습에서는 측정 파일의 전체 2,000행 중 필요한 11개 열을 CSV로 옮긴 sports100-practice.csv를 사용합니다. 값과 결측값은 원본 그대로 유지했으며, 회원번호와 분석에 사용하지 않는 열은 포함하지 않았습니다. 변수 설명도 sports100-variables.csv로 제공합니다.

원고의 일부 설명에는 청소년 1,000명으로 기재되어 있으나, 실제 파일은 청소년·성인·어르신이 함께 있는 2,000건입니다. 이 장에서는 파일을 확인한 결과에 따라 분석 대상을 정합니다. 자료의 한 행을 측정 기록 한 건으로 해석하며, 표본의 모집단 대표성이 확인된 자료로 가정하지 않습니다.

강의 프로젝트를 사용하는 경우 자료는 data 폴더에 있습니다. 파일을 개별로 내려받으면 실습 CSV와 변수 설명 CSV를 Rmd 또는 R 코드가 있는 폴더의 data 하위 폴더에 저장합니다. 실행 파일이 있는 폴더를 작업 폴더로 지정합니다. 이 자료는 원본 강의에 포함된 표본 파일을 사용합니다.

4.2 분석 자료 구성과 결측값 점검

4.2.1 변수 이름과 자료형 정리

select()로 필요한 열을 고르면서 읽기 쉬운 이름을 부여합니다. mutate()는 열의 변환 또는 생성을, filter()는 조건에 맞는 행의 선택을 수행합니다. %>%는 앞 단계의 결과를 다음 함수로 전달합니다.

nfa <- nfa_raw %>%
  select(
    age_group = AGE_GBN, age = TEST_AGE, test_date = TEST_MD,
    sex = TEST_SEX, height_cm = ITEM_F001, weight_kg = ITEM_F002,
    grip_left = ITEM_F007, grip_right = ITEM_F008,
    curl_up = ITEM_F009, jump_count = ITEM_F010, bmi = ITEM_F018
  ) %>%
  mutate(
    test_date = as.Date(test_date),
    year = factor(format(test_date, "%Y")),
    sex = factor(sex, levels = c("M", "F"), labels = c("남성", "여성")),
    age_group = factor(age_group, levels = c("청소년", "성인", "어르신"))
  )

teen_raw <- nfa %>%
  filter(age_group == "청소년", age >= 13, age <= 18)

원본 예제는 두 근지구력 항목을 선택 측정 항목으로 설명합니다. 실제 청소년 자료에는 윗몸말아올리기만 있는 기록 334건, 반복점프만 있는 기록 493건, 둘 다 있는 기록 1건, 둘 다 없는 기록 19건이 있습니다. 따라서 모든 열에 na.omit()을 적용하면 분석에 필요하지 않은 항목의 결측값 때문에도 기록이 제외됩니다.

윗몸말아올리기를 측정하지 않은 경우의 NA와 실제 수행 횟수 0회를 구분해야 합니다. 결측값을 0으로 바꾸면 평균과 회귀계수가 달라집니다. 이후에는 각 분석에 필요한 변수에 대해서만 사용 가능한 기록을 선택합니다.

4.2.3 변수 설명서의 범위 확인

column_info.xlsx의 min_teen, max_teen에는 청소년 측정값의 점검 범위가 제시되어 있습니다. 이 범위는 제공된 강의 자료의 점검 기준이며, 임상적 정상 범위나 공식 체력 인증 기준으로 해석하지 않습니다.

nfa_info %>%

윗몸말아올리기 120회인 기록 3건이 설명서의 상한 100회를 초과합니다. 이 사실만으로 입력 오류라고 단정할 수는 없습니다. 본 실습의 주 분석에서는 해당 값들을 제외 대상으로 표시하고, 원본 값을 보존한 별도 열에서 결측값으로 처리합니다. 마지막 과제에서는 이 세 건을 포함했을 때 결과가 달라지는지 비교합니다.

teen <- teen_raw %>%
  mutate(
    curl_flag = !is.na(curl_up) & (curl_up < 0 | curl_up > 100),
    curl_clean = ifelse(curl_flag, NA_real_, curl_up)
  )

체중과 좌우 악력은 위의 점검에서 범위 밖 값이 없으므로 그대로 사용합니다. 다른 자료를 분석할 때에는 해당 점검 결과에 따라 처리 여부를 판단해야 합니다.

4.2.4 상대악력 계산과 분석 표본 확정

원본 예제와 동일하게 좌우 악력 중 큰 값을 체중으로 나누어 상대악력을 계산합니다.

\[ \text{상대악력}(\%)= \frac{\max(\text{왼손 악력},\text{오른손 악력})}{\text{체중}}\times100 \]

teen <- teen %>%
  mutate(
    grip_max = pmax(grip_left, grip_right, na.rm = TRUE),
    grip_max = ifelse(is.na(grip_left) & is.na(grip_right), NA_real_, grip_max),
    grip_rel = ifelse(weight_kg > 0, grip_max / weight_kg * 100, NA_real_)
  )

reg_data <- teen %>%
  filter(!is.na(sex), is.finite(grip_rel), is.finite(curl_clean))

sample_flow <- data.frame(
  단계 = c("원본 측정 기록", "13–18세 청소년", "상대악력 계산 가능",
           "윗몸말아올리기 측정", "범위 점검 후 윗몸말아올리기",
           "두 변수와 성별이 있는 회귀분석 자료"),
  기록수 = c(nrow(nfa_raw), nrow(teen), sum(is.finite(teen$grip_rel)),
             sum(!is.na(teen$curl_up)), sum(!is.na(teen$curl_clean)), nrow(reg_data))
)

이 자료에서는 체중의 변동계수가 더 큽니다. 신장의 표준편차는 cm, 체중의 표준편차는 kg 단위이므로 그 수치만으로 상대적 변동을 비교할 수는 없습니다. 변동계수는 각 평균을 기준으로 산포를 나타냅니다.

4.6.2 과제 2 · 도수와 비율 그래프

연도별 성별 비율을 나타내는 누적 막대그래프를 작성합니다. 앞에서 작성한 도수 그래프와 비교하여, 각 그래프가 어떤 질문에 답하는지 설명합니다.

과제 2 해설 
ggplot(teen, aes(x = year, fill = sex)) +
  geom_bar(position = "fill") +
  scale_y_continuous(breaks = seq(0, 1, 0.25),
                     labels = c("0%", "25%", "50%", "75%", "100%")) +
  labs(x = "측정 연도", y = "연도 내 비율", fill = "성별")

도수 그래프는 기록 수를, 비율 그래프는 각 연도 안의 성별 구성을 나타냅니다. 비율이 같아도 실제 기록 수는 다를 수 있으므로 도수표도 함께 제시합니다.

4.6.3 과제 3 · 여성 청소년의 회귀모형

여성 청소년의 상대악력으로 윗몸말아올리기를 설명하는 단순선형회귀모형을 적합합니다. 표본 수, 기울기, 결정계수, RMSE를 구하고 남성 모형과 비교합니다. 다른 집단의 결정계수 차이를 곧바로 예측 능력의 우열로 해석할 수 있는지도 검토합니다.

과제 3 해설 
female_data <- reg_data %>% filter(sex == "여성")
fit_nfa_female <- lm(curl_clean ~ grip_rel, data = female_data)

data.frame(
  sex = c("남성", "여성"),
  n = c(nobs(fit_nfa), nobs(fit_nfa_female)),
  slope = c(unname(coef(fit_nfa)[2]), unname(coef(fit_nfa_female)[2])),
  R_squared = c(summary(fit_nfa)$r.squared, summary(fit_nfa_female)$r.squared),
  RMSE = c(sqrt(mean(resid(fit_nfa)^2)), sqrt(mean(resid(fit_nfa_female)^2)))
)

두 모형은 서로 다른 관측값과 반응변수 분포에서 구한 결과입니다. 계수의 크기와 불확실성, 산포, 표본 수를 함께 확인합니다. 집단별 계수의 차이를 검정하려면 별도의 모형과 검정이 필요합니다.

4.6.4 과제 4 · 범위 점검의 영향을 비교하기

주 분석에서 제외한 윗몸말아올리기 120회 기록을 포함하여 남성 모형을 다시 적합합니다. 분석 결과가 값의 처리 방식에 얼마나 민감한지 비교하고, 보고서에 기록해야 할 사항을 작성합니다.

과제 4 해설 
male_all <- teen %>%
  filter(sex == "남성", is.finite(grip_rel), is.finite(curl_up))
fit_nfa_all <- lm(curl_up ~ grip_rel, data = male_all)

data.frame(
  analysis = c("설명서 범위 적용", "원래 측정값 포함"),
  n = c(nobs(fit_nfa), nobs(fit_nfa_all)),
  slope = c(unname(coef(fit_nfa)[2]), unname(coef(fit_nfa_all)[2])),
  R_squared = c(summary(fit_nfa)$r.squared, summary(fit_nfa_all)$r.squared),
  RMSE = c(sqrt(mean(resid(fit_nfa)^2)), sqrt(mean(resid(fit_nfa_all)^2)))
)
          analysis   n     slope R_squared     RMSE
1 설명서 범위 적용 206 0.6319850 0.1212473 22.00608
2 원래 측정값 포함 209 0.6720695 0.1206257 23.46887

원래 값과 제외 사유를 보존하고, 사용한 기준과 각 분석의 표본 수를 보고합니다. 결정계수가 더 높거나 p값이 더 작다는 이유로 처리 방식을 선택하지 않습니다. 원자료 제공자에게 측정 단위·상한·입력 관행을 확인할 수 있다면 그 정보를 우선하여 판단합니다.

4.6.5 보고서 작성과 결과 저장

다음 요소를 포함하여 1–2쪽 분량의 분석 보고서를 작성합니다.

  1. 자료와 분석 대상: 자료의 출처, 연령 조건, 측정 기간, 분석 기록 수를 제시합니다.
  2. 자료 처리: 결측값과 범위 밖 값의 처리, 상대악력 계산 방법을 설명합니다.
  3. 기술통계와 시각화: 요약표 1개, 분포 그림 1개, 관계 그림 1개를 제시하고 단위와 분모를 명시합니다.
  4. 회귀분석: 회귀식, 기울기의 해석, 결정계수와 RMSE, 잔차 진단을 제시합니다.
  5. 예측과 한계: 점예측과 구간을 구분하고, 횟수 자료에 선형모형을 적용한 한계와 표본의 적용 범위를 서술합니다.

다음은 주 분석 결과를 정리한 문장 예시입니다.

제공된 2,000건의 측정 기록 중 13–18세 청소년 847건을 선정하였다. 상대악력과 범위 점검을 통과한 윗몸말아올리기 값이 모두 있는 남성 청소년 206건으로 단순선형회귀분석을 수행하였다. 상대악력이 10퍼센트포인트 큰 경우 추정한 평균 수행 횟수는 약 6.32회 많았다. 결정계수는 0.121, 적합 자료의 RMSE는 22.01회였다. 양의 관계가 관찰되었으나 개인별 퍼짐이 크고 예측구간에 음수가 포함되어, 이 모형만으로 개인의 수행 횟수를 예측하는 데 한계가 있다. 이 관계를 훈련 효과나 전체 청소년의 특성으로 일반화하지 않았다.

필요한 경우 요약표와 그래프를 저장합니다. 다음 코드는 직접 실행할 때에만 파일을 생성합니다.
